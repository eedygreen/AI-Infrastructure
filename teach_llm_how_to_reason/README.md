# Teach LLM How to Reason

This directory contains resources and code examples for teaching large language models (LLMs) how to reason effectively. 
The `requirements.txt` file contains the necessary dependencies to run the code examples on Google Colab.

| Some of the dependencies included are specific to Google Colab, such as `google-colab` and others.

### LoRA Adapter
The `grpo_saved_lora` directory contains a LoRA adapter that can be used to fine-tune LLMs for reasoning tasks. Here is the trained LoRA adapter:
