### **OLD Project 5:**
- Simple Web3-AI hybrid app
- Single sentiment analysis model
- Basic Lambda deployment

### **NEW Project 5: Multi-Agent Trading Intelligence System**

**Three Specialized Agents:**
1. **Research Agent**
   - Scrapes crypto news (CoinDesk, Twitter)
   - Fetches real-time prices (CoinGecko)
   - Queries on-chain data (Etherscan)
   - Stores findings in Pinecone

2. **Analysis Agent**
   - Technical analysis (price patterns, volume)
   - Sentiment scoring using fine-tuned model
   - Risk calculation based on volatility
   - Retrieves context from Pinecone

3. **Decision Agent**
   - Aggregates insights from other agents
   - Generates trading recommendations (buy/sell/hold)
   - Confidence scoring
   - Writes results back to smart contract

**Infrastructure:**
- LangGraph orchestration
- AWS Lambda deployment
- DynamoDB for agent state
- LangSmith for observability
- Cost tracking ($/execution)
- Rate limiting & error handling

**Why This is Better:**
- Shows real multi-agent systems (hot in 2025!)

- Security-conscious (sandboxing, rate limits)
- Observable (LangSmith traces)
